# Proyeksi dan proporsi peta

Peta versi 3 memakai proyeksi silinder setara luas (Lambert, model bumi bulat). Luas relatif dipertahankan lebih baik di seluruh rentang peta daripada Mercator: sekitar 40° LU, Mercator membesarkan luas sekitar 1,7 kali dibandingkan di khatulistiwa. Bentuk dan jarak tetap terdistorsi, terutama di utara; ini adalah kompromi proyeksi, bukan batas historis yang presisi. Sumber: [ArcGIS: Mercator](https://pro.arcgis.com/en/pro-app/3.5/help/mapping/properties/mercator.htm), [USGS: Map Projections](https://pubs.usgs.gov/pp/1395/report.pdf).

Garis pantai berasal dari world-atlas; batas provinsi dan kepemilikan adalah pendekatan permainan, bukan peta politik terverifikasi tahun 1350. Wilayah kekuasaan langsung dan pengaruh atau hubungan upeti Majapahit tidak harus identik. Zoom minimum tetap memperlihatkan seluruh peta.

ID dan nama provinsi tidak berubah. Saat save versi 1 dimuat, transformasi lama diterapkan terlebih dahulu; armada versi 2 diproyeksikan ke koordinat baru dan rute aktifnya dihitung ulang. Muatan disimpan. Jika rute tidak dapat ditemukan, perintah dibatalkan dan pemain diberi catatan untuk memerintahkannya kembali.
